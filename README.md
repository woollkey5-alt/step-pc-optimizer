# STEP PC Optimizer 1.0

Понятные настройки Windows для игр: диагностика, необязательные автозапуски, выбор существующей схемы питания и возврат из сохранённой копии. Профиль CS2 помогает выбрать настройки Windows и даёт ручные рекомендации для игры. Рост FPS не гарантируется.

**Как начать**

1. [Скачайте STEP-PC-Optimizer-1.0.zip](https://github.com/woollkey5-alt/step-pc-optimizer/releases/download/v1.0/STEP-PC-Optimizer-1.0.zip). Если требуется, установите **.NET 9 Desktop Runtime x64** с [официального сайта Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/9.0) — выбирайте Desktop Runtime.
2. Распакуйте архив целиком. Откройте папку `app` и запустите `PCOptimizer.exe`. DLL и JSON-файлы должны оставаться рядом с EXE.
3. Во вкладке активации введите полученный код покупки и нажмите «Активировать онлайн». Затем выберите нужные действия; программа покажет их и запросит подтверждение перед изменениями.

**Лицензия:** START7 — 7 дней, BASIC30 — 30 дней, PRO180 — 180 дней, LIFETIME — бессрочно. Функции одинаковые, одна лицензия — один ПК. После онлайн-активации подписанный доступ работает до 7 дней без сети, в пределах оплаченного срока. Диагностика и восстановление копий доступны без лицензии и после окончания срока.

**Проверка файлов:** [EXE](https://www.virustotal.com/gui/file/fe0e83b37f52814cec717f7d4a0c29dadee36d4200df4f2da83ed7d1d89c274e/detection) · [собственная DLL](https://www.virustotal.com/gui/file/10858293877aecfcef4cedfc03f83e93f37478af773d86290968a2c80232f10c/detection) · [ZIP](https://www.virustotal.com/gui/file/cb1a34452512a650264325ffda230788b4025a7bdefd631c4f5f63077d718d7c/detection). В сохранённом отчёте DLL **1/68: SecureAge — Malicious**; запрос на пересмотр отправлен, решение пока не подтверждено. Программа без сертификата цифровой подписи; ни один AV-отчёт не гарантирует 100% безопасности. Подробности — [SECURITY.md](SECURITY.md), контрольные суммы — [SHA256.txt](SHA256.txt).

Публичное имя выпуска — **1.0**; внутренняя версия неизменённой сборки — **0.2.1**. [Открытые исходники для проверки](https://github.com/woollkey5-alt/step-pc-optimizer/releases/download/v1.0/PCOptimizer-0.2.1-source-review.zip).
