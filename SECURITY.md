# Проверка и ограничения STEP PC Optimizer 1.0

Публичный выпуск 1.0 содержит неизменённую внутреннюю сборку 0.2.1. Переименование ZIP не меняет его содержимое или SHA256. Это обычная папка приложения .NET 9 для Windows x64, использующая установленный Desktop Runtime. Нет single-file, self-contained, упаковщика, обфускации или установки службы. EXE — стандартный apphost; логика находится в собственной `PCOptimizer.dll`, поэтому проверка только EXE недостаточна.

## Действия программы

Изменения выполняются только после выбора и подтверждения. Сначала сохраняется атомарная копия исходного состояния, затем удаляются выбранные разрешённые записи **HKCU Run** либо выбирается уже существующая схема питания. Разрешённые семейства: Discord, Spotify, Teams, Steam, Epic Games Launcher, Zoom и Skype; проверяются имя, тип значения и путь команды. Проверка формы пути не является проверкой цифровой подписи соответствующего приложения.

Программа не закрывает процессы, не меняет защиту, античит, службы, драйверы, файлы CS2, BIOS или разгон. Manifest — `asInvoker`, повышения прав нет. CS2-профиль — настройки Windows и ручные игровые рекомендации, без скрытой автоматической правки игры. Рост FPS не гарантируется.

Восстановление доступно без лицензии, офлайн и после окончания срока. Оно пропускает значения, которые пользователь изменил после применения; копии сохраняются у текущего пользователя. XML-копии проверяются по структуре и принадлежности, но не являются подписанной границей защиты от владельца текущей учётной записи.

## Активация и данные

Активация передаёт только введённый код и SHA256 Machine ID по HTTPS на `https://woolkey-pc-tune-download.zhdanova184.chatgpt.site/api/activate`. Machine ID основан на SMBIOS UUID, при его отсутствии — серийном номере платы. GPU, RAM, SSD, имя пользователя и имя компьютера не входят в отправляемый ID. Сведения WMI-диагностики не отправляются на сервер. Имя компьютера и SID используются только локально для принадлежности копий.

Код и подписанный доступ хранятся локально с DPAPI текущего пользователя. Перенаправления запрещены; запрос ограничен 10 секундами, ответ — 64 KiB. Проверяется RSA SHA256-подпись, оплаченный срок, привязка к ПК и срок офлайн-доступа. Офлайн-доступ — до 7 дней, не дольше оплаченного срока. Ошибка сети не заменяет хороший кэш. Автоматическое обновление по условиям срока — не более одной попытки за сеанс программы; отдельного фонового процесса нет. Восстановление не зависит от сервера.

START7/BASIC30/PRO180/LIFETIME дают одинаковые функции и отличаются сроком 7/30/180 дней или бессрочно. Одна лицензия рассчитана на один ПК. При смене материнской платы или изменении SMBIOS ID может потребоваться ручная перевыдача. Старые подписанные XML-лицензии поддерживаются. Приватные ключи выдачи, пароли, администраторские токены и настоящие коды покупки не входят в поставку.

## Исходники и проверки

Публичный архив исходников совпадает с четырьмя компилируемыми `.cs`, проектом, manifest и `build.ps1` этой сборки. Исходники сохраняют вспомогательные тесты под `DEVELOPMENT_TOOLS`; покупательская сборка не содержит семи внутренних CLI-команд, fake adapters, тестовых генераторов, скрытого тестового запуска и экспорта preview. Отдельная тестовая сборка не поставляется.

Записаны 45 изолированных проверок (20 ядра, 11 лицензирования, 14 облачного клиента), обычный запуск production GUI и отдельная проверка онлайн-активации через точную production DLL. Они не измеряют рост FPS и не заменяют аудит всех возможных уязвимостей. Реальные автозапуски и схема питания рабочего ПК при этих проверках не изменялись.

Сборка записана как SDK 9.0.308, `net9.0-windows`, Release, win-x64, framework-dependent, `DefineConstants=TRACE`. Независимая побайтно воспроизводимая пересборка не выполнялась. В source ZIP отсутствует `global.json`; для повторения выбора SDK используйте 9.0.308 с `rollForward: disable`. Успешный build log и совпадение исходников поддерживают происхождение, но не являются полной доказанной воспроизводимостью.

`System.Management.dll` — официальный пакет Microsoft System.Management 9.0.11. Его отдельная контрольная сумма приведена в `SHA256.txt`; исходные уведомления Microsoft входят в `app/third-party-notices`. Запакованный ZIP не заменяет проверку отдельных компонентов.
